[SIZE="5"][B]ARC Raiders External ESP — Final Source Release[/B][/SIZE]

This is a one-time experimental release of a C# external overlay and its source code. The same archive includes the compiled x64 project executables, build scripts, tests and native source material. There will be no follow-up release posts.

[B]Read this before downloading:[/B] this is a source snapshot, not a verified current-patch release. Live-game compatibility and detection status have not been established. The reader contains game-specific offsets, and the optional team/bone/visibility profile is disabled because its fields have not been verified for a specific build.

[SIZE="4"][B]Features[/B][/SIZE]
[LIST]
[*]Player boxes, distance labels, radar and off-screen indicators.
[*]Configurable appearance, refresh rate, range and horizontal/vertical FOV interpretation.
[*]Team, visibility and skeleton labels when a compatible profile is present.
[*]Manual teammate exclusions with F6/F7 and optional display filters.
[*]Source code and scripts to rebuild the project executables.
[/LIST]

[SIZE="4"][B]What actually works without a target profile[/B][/SIZE]
The overlay draws when the base position/camera reader matches your test build. It does not automatically distinguish unknown teammates from enemies or confirm walls; manual teammate marks can be hidden from ESP and unknown data stays labelled as unknown. The supplied profile does not provide working team, bone or raycast offsets, so team, visibility and skeleton metadata stay unknown until a verified profile is supplied.

[SIZE="4"][B]Requirements[/B][/SIZE]
[LIST]
[*]x64 Windows 11, .NET Framework 4.8 and the x64 Visual C++ runtime.
[*]Your own local LiveKD 5.65 installation, x64 Debugging Tools components and kernel symbols matching your Windows build.
[*]A compatible test build of the target process, PioneerGame.exe.
[*]Administrator rights for the local acquisition tool.
[/LIST]

LiveKD, Microsoft debugging binaries, Visual C++ redistributables and kernel PDBs are not bundled. Configure their local paths using local-prerequisites.example.json and the included README. The launcher does not download prerequisites, open websites or configure an online symbol server. There is no updater or login system in the project.

[SIZE="4"][B]Setup and controls[/B][/SIZE]
[LIST=1]
[*]Extract the complete archive into a writable folder.
[*]Create local-prerequisites.json from the example and set the paths to your existing local prerequisites. Use the kernel PDB for your Windows build, not a random PDB with the same filename.
[*]Launch Abrir-ESP.exe and accept its administrator prompt.
[*]Use INSERT to review settings, close the menu, and focus the game.
[*]Use F6/F7 to mark teammates you want hidden from the overlay.
[/LIST]

[LIST]
[*][B]INSERT:[/B] settings menu.
[*][B]F6:[/B] mark/unmark one unambiguous player under the crosshair as a teammate.
[*][B]F7:[/B] clear session marks.
[*][B]F10:[/B] close the overlay.
[/LIST]

The application UI retains Spanish labels; the release documentation is in English. Manual marks expire after five seconds without observing an actor and reset on world/local-character changes. The retained automatic session limit is one hour.

[SIZE="4"][B]Source and build[/B][/SIZE]
The archive includes the managed overlay and launcher source, an installed-compiler resolver, deterministic x64 build scripts and synthetic tests. Recompilar.ps1 rebuilds the two project EXEs and updates their hashes.

[CODE]
powershell -NoProfile -ExecutionPolicy Bypass -File .\Recompilar.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Probar-LiveKd.ps1 -Mode Verify
powershell -NoProfile -ExecutionPolicy Bypass -File .\pruebas\Verificar.ps1
[/CODE]

The native source material includes MemProcFS v5.19 source and the complete modified LeechCore source baseline, along with its reproducible File-backend serialization adjustment. Read NATIVE-SOURCES.md and retain the upstream license notices.

[SIZE="4"][B]Validation and limitations[/B][/SIZE]
The recorded full run passed all 24 suites of the previous revision. The aim-assist, autofire and relative-mouse input features, and their nine suites, were then removed; the retained 15 suites cover discovery, teams, profile data, bone transforms, projection, radar and timer lifecycle and are unchanged except for the removed aim checks. The Windows timer test failed its latency threshold in two earlier batch runs, then passed in an isolated run and the final batch. That intermittent failure remains documented. These tests use synthetic data and do not demonstrate in-game functionality.

Native export loading is verified with the reduced runtime. The concurrent File-backend stress test and final artifact checks are documented in VALIDATION.md. End-to-end acquisition with the public package remains unverified.

The base reader can break with a game update. Projection does not fully support aspect-constrained or off-center cameras. Life/downed state is not checked, and a camera-ray visibility label describes the camera ray, not the weapon path. No claim of an undetected or universally compatible release is made.
