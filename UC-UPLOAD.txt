Description:
[B]ARC Raiders ESP — 1.0 Final[/B]

One-time experimental source and binary snapshot of a C# external overlay.
Includes the x64 project executables, complete managed source, build scripts,
synthetic tests, documentation and version-pinned native source material.

Features include ESP boxes, distances, radar, off-screen indicators and manual
telemate exclusions. The optional team/bone/visibility profile is disabled and
unverified; without it team, visibility and skeleton labels stay unknown.

Requires x64 Windows 11, .NET Framework 4.8, the x64 Visual C++ runtime and locally
installed LiveKD 5.65, x64 Debugging Tools components and matching kernel symbols.
Those Microsoft prerequisites are not bundled. No prerequisite downloader or
updater is included. See README.md for local configuration and SOURCE-GUIDE.md
for the implementation and its limitations.

Current public-game compatibility and detection status are unverified. The
functional synthetic suites pass; the recorded Windows timing test has an
intermittent latency failure. The archive includes the validation record and
the upstream license notices for its distributed native components.
